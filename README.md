# blogbutler
A simple blog builder. Takes markdown and builds it to html with styles,
templates, and more. Also has a serve command using go's build in file server.

## Installation

Download a binary from the [releases](https://github.com/marcusleonas/blogbutler/releases) page
then place it in your path.
